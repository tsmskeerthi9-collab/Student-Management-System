# Student Management System

A lightweight, secure relational database management engine built with Python and SQLite to manage student records efficiently.

## Features
- *Data Integrity*: Uses SQLite constraints to ensure duplicate IDs are not allowed.
- *Robust Validation*: Prevents application crashes from invalid user inputs (e.g., non-numeric age inputs).
- *Secure Connections*: Implements Python context managers (with statements) for safe database session lifecycles.

## Tech Stack
- *Language*: Python 3.x
- *Database*: SQLite3

## How to Run
1. Clone the repository:
   bash
   git clone https://github.com
   
2. Navigate to the project directory:
   bash
   cd Student-Management-System
   
3. Run the application:
   bash
   python main.py
